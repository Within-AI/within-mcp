Start here for most questions about how work gets done.

| Tool | When to use |
|---|---|
| `search` | Find processes related to a question, topic, or business activity. |
| `fetch` | Read a process you have found before explaining how it works. |

## The default loop

1. Search using the user's words. Try related terms if the results are sparse.
2. Read the matching processes to understand their steps and relationships.
3. Follow up with [Process Index tools](/tools/process-index) for more detail or [process observations](/tools/observations-and-changes) for evidence from captured work.

If you already have a process from an earlier result, go straight to `fetch`. To browse instead of search, start with [`get_process_hierarchy`](/tools/process-index).
