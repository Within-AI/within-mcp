Use these tools to explore the process index or investigate a process in more detail.

| Tool | When to use |
|---|---|
| `search_processes` | Find a process, department, or value stream related to your question. |
| `get_process_hierarchy` | Browse how the organization's work is organized when you do not know where to start. |
| `get_hierarchy_node_details` | Explore a particular group in the index and the processes beneath it. |
| `get_process_details` | Understand a process's work, policies, supporting evidence, history, and dependencies. |

## Common workflows

- **Explore a business area:** browse the hierarchy, open a relevant group, then read its processes.
- **Understand dependencies:** read a process and follow its relationships to other processes.
- **Check how work happens in practice:** find a process, then use [observations and activity timelines](/tools/observations-and-changes) to examine captured work.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | Yes | Search text. |
| `top_k` | integer | No | Result limit. Default: `10`. Range: 1–10. |

```json
{
  "context": "Find invoice approval processes.",
  "query": "invoice approval",
```

<Accordion title="get_process_details">

| Parameter | Type | Required | Description |
|---|---|---|---|
| `process_resource_key` | string or null | No | Process identifier. Default: `null`. |
| `process_name` | string or null | No | Process name. Default: `null`. |
| `scope` | array of string or null | No | Details to include. Default: `null`. Values: `tasks`, `observations`, `dependencies`, `attributes`, `history`, `linked_artifacts`, `policies`. |

Supply a process identifier or name. The identifier takes precedence when both are provided.

```json
{
  "context": "Read invoice approval details.",
  "process_name": "Invoice approval",
  "scope": [
    "tasks",
    "dependencies"
  ]
}
```
