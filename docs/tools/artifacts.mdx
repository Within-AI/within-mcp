Artifacts are the source materials behind processes, including documents, recordings, screenshots, and diagrams.

| Tool | When to use |
|---|---|
| `search_artifacts` | Find documents or recordings relevant to a question. |
| `get_artifact_details` | Learn about a source and discover related materials. |
| `get_artifact_content` | Read a source's extracted text or a specific passage. |
| `search_artifact_text` | Locate a phrase or pattern within a source you have already found. |

## Common workflows

- **Support an answer with a citation:** find a source, locate the relevant passage, then read it in context before quoting it.
- **Review a procedure:** find its document and read the relevant sections.
- **Find related evidence:** inspect a source's details and follow its links to other materials.

Use `search_artifacts` to search across sources and `search_artifact_text` to search within one source.

<Accordion title="search_artifacts">

| Parameter | Type | Required | Description |
|---|---|---|---|
| `query` | string | Yes | Search text. Minimum length: 1. |
| `top_k` | integer | No | Result limit. Default: `5`. Range: 1–10. |
| `semantic_top_k` | integer | No | Meaning-based search limit. Default: `5`. Range: 1–50. |
| `lexical_top_k` | integer | No | Keyword search limit. Default: `5`. Range: 1–50. |
| `semantic_min_score` | number | No | Relevance threshold. Default: `0.3`. Range: 0.0–1.0. |
| `artifact_resource_keys` | array of string or null | No | Sources to include. Default: `null`. |
| `artifact_types` | array of string or null | No | Source types. Default: `null`. Values: `video`, `audio`, `document`, `diagram`, `log`, `image`, `folder`, `skill_package`, `rav_session_data`, `session_analysis`. |
| `origin_types` | array of string or null | No | Source origins. Default: `null`. Values: `user_input`, `system_input`, `ai_generated`, `system_processed`, `gold_document`, `ai_generated_migrated`. |
| `file_types` | array of string or null | No | File types. Default: `null`. |
| `only_verified` | boolean or null | No | Filter by verification status. Default: `null`. |
| `created_after` | string (date-time) or null | No | Created after this time. Default: `null`. |
| `created_before` | string (date-time) or null | No | Created before this time. Default: `null`. |
| `max_snippets_per_artifact` | integer | No | Snippets per source. Default: `2`. Range: 1–5. |

**Example request**

```json
{
  "context": "Find invoice approval policies.",
  "query": "invoice approval policy",
  "top_k": 5
}
```

<Accordion title="get_artifact_content">

| Parameter | Type | Required | Description |
|---|---|---|---|
| `resource_key` | string | Yes | Source identifier. |
| `mode` | string | No | Reading mode. Default: `"preview"`. Values: `preview`, `range`. |
| `start_line` | integer or null | No | First line. Default: `null`. Minimum: 1. |
| `end_line` | integer or null | No | Last line. Default: `null`. Minimum: 1. |

Range mode requires both line numbers, with the end at or after the start.

**Example request**

```json
{
  "context": "Read the selected passage.",
  "resource_key": "artifact_example",
  "mode": "range",
  "start_line": 1,
  "end_line": 20
}
```

<Accordion title="search_artifact_text">

| Parameter | Type | Required | Description |
|---|---|---|---|
| `resource_key` | string | Yes | Source identifier. |
| `query` | string | Yes | Search text. |
| `before_chars` | integer | No | Context before each match. Default: `100`. Range: 0–2000. |
| `after_chars` | integer | No | Context after each match. Default: `100`. Range: 0–2000. |
| `max_matches` | integer | No | Match limit. Default: `5`. Range: 1–20. |
| `use_regex` | boolean | No | Enable pattern matching. Default: `true`. |
| `ignore_case` | boolean | No | Ignore letter case. Default: `true`. |

**Example request**

```json
{
  "context": "Find approval references.",
  "resource_key": "artifact_example",
  "query": "approval",
  "use_regex": false
}
```
