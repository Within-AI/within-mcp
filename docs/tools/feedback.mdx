---
title: "Feedback"
description: "Submit optional, explicitly approved feedback about the MCP integration."
icon: "comment"
---

`submit_feedback` sends feedback to Within product analytics. It is a write tool (`readOnlyHint: false`), but does not edit customer processes, artifacts, or graph entities. Call it only after the user provides explicit feedback and approves submission. Copy the feedback verbatim, without adding conversation context.

| Argument | Schema |
|---|---|
| `sentiment` | Required: `positive`, `negative`, or `mixed` |
| `text` | Required string, 1–2,000 characters; the user's exact feedback |
| `context` | Required shared tool-call intent context |
| `mcp_thread_id` | Optional shared correlation identifier |

A successful call returns `submitted: true`, plus the shared response metadata. Analytics receives the feedback text, sentiment, text length, source (`mcp`), workspace and organization resource keys, request ID, and the analytics distinct ID. Tool-call audit logging treats `text` as sensitive and records its length instead of its contents. The feedback text itself is sent to analytics.
