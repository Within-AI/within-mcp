Use these tools to orient yourself in a workspace and find its contributors.

| Tool | When to use |
|---|---|
| `list_accessible_workspaces` | Confirm which workspace is active and see the other workspaces you can access. |
| `list_users` | Browse the workspace directory to find people and identify contributors. |

## User directory

The directory lists active people in the current workspace, with their names, email addresses, and workspace roles. Workspace admins can also see the last recorded sign-in time. Available information depends on your access.

Use the directory with [`list_sessions`](/tools/observations-and-changes) to explore a person's contributions.

## Switching workspaces

Each connection is scoped to one workspace.

- **OAuth:** disconnect and reconnect to choose a different workspace.
- **API key:** use a key issued for the workspace you want to access, where API keys are available.

See [Switching workspaces](/authentication#switching-workspaces) for details.
