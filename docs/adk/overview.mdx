The Agent Development Kit (ADK) is a plugin from Within that takes the way your teams actually work, as captured in your Work Brain, to a designed and tested agent. It runs inside Claude Code, Cowork, or Codex.

## How it relates to the Within MCP

Download the ADK ZIP from **Settings → Downloads** in the Within web app and follow the kit's setup instructions. It doesn't replace the Within MCP; it uses it. Agent Recommendations reads process evidence through your client's existing [Within MCP connection](/quickstart), and the later modules work from a Work Brain Snapshot saved in the run folder.

## Modules

Run each module on its own, or one after another.

| Module | What it does |
|---|---|
| **Agent Recommendations** | Finds where agents could help, grounded in Work Brain process evidence, and recommends what to build. |
| **Future State Design** | Maps the Current state Workflow of one process or a set of related processes, how the work is reshaped, and the Future state Workflow. |
| **Agent Design** | Designs the agent from that future state: architecture, boundaries, decision rules, placement, fields, test suite, and a simulation. |
| **Agent Build** | Builds the agent in a sandbox you agree at planning and checks it against frozen expected results. Claude Code and Codex only. |
