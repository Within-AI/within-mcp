---
title: "Download and install"
description: "Download the Agent Development Kit ZIP from the Within web app."
icon: "download"
---

1. In the Within web app, open **Settings → Downloads**.
2. Download the **Agent Development Kit (ADK)** ZIP available there.
3. Follow the kit's setup instructions for your AI client.

Access to Downloads requires permission to view workspace settings. If you cannot access it, ask your workspace admin for the kit.

Connect the [Within MCP](/quickstart) in your client so the kit can use your workspace's process evidence. See the [ADK overview](/adk/overview) for its modules and supported clients.
