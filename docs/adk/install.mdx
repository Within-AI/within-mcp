Download the ADK from your Within workspace, then install it in the client your team works in. See the [overview](/adk/overview) for what each module does.

## Requirements

| | Claude Code | Cowork | Codex |
|---|---|---|---|
| Agent Recommendations, Future State Design, Agent Design | Yes | Yes | Yes |
| Agent Build | Yes | No | Yes |

- **Python 3.9 or later.** The ADK uses the standard library only and installs nothing. In Cowork, your administrator sets up Python.
- **Within MCP connected** in the same client, so Agent Recommendations can read your Work Brain. See [Quickstart](/quickstart) for your client.

## Download

<Steps>
  <Step title="Open Settings">
    In your Within workspace, go to **Settings → Downloads**.
  </Step>
  <Step title="Download the kit">
    Download the latest **Agent Development Kit** zip, for example `agent-development-kit-2.0.zip`. The changelog sits alongside it.
  </Step>
</Steps>

<Note>
  The Downloads tab is visible to workspace admins only. If you can't see it, ask your workspace admin for the kit.
</Note>
