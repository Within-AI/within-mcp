How to read this

  • Bands show who does the work. Left to right is the order of the work; systems are rails at the bottom that steps read from and write to.
  • Three performer bands: Analyst (top) - Agent (middle) - System (bottom). The Agent mediates. read_access edges flow down from System to Agent (and person-retained reads from System to Analyst); handoff edges flow up from Agent to Analyst carrying draft/recommendation output; every write edge originates in the Analyst lane and targets a System surface. Control-flow sequence/then/else/merge/loop/exception edges connect acts and may cross lanes; the directional constraint governs the access, handoff, and write edges, not control-flow sequence. The System lane holds passive system_surface nodes and preserved system_result nodes; it performs nothing.
  • recommend-then-review (decision log 0014, ratified). The agent assembles the permitted evidence, applies only explicitly approved matching logic, and returns an evidence-backed recommended assessment as a draft, or an Escalation. The analyst reviews, holds every authoritative decision (with authority to override), and performs every system action. No decision node is agent-taken.
  • Access to every surface is an Assumed design condition for this exercise (decision log 0014, evt-0085), not a verified client entitlement. Availability is not an access grant. Each of the named surfaces carries an access disposition of More information required in the access-feasibility register; this graph upgrades none of them. Assumed access must never be represented as client-verified or production-ready.
  • The agent never clears, writes, saves, completes, applies, uploads, assigns, classifies, sends, performs outreach, or executes an operational Escalation in any system. No write edge originates from an Agent-lane node; the agent writes to nothing it does not own. Its only output leaves the lane via handoff to the agent review surface / Excel draft columns. Every write edge originates in the Analyst lane and targets a System surface (or, for the Excel classification and the Bank->CSV export, an Analyst-lane workspace with no System write edge). A single agent-originated write, or an agent-owned authoritative decision, is a critical violation.
  • The required threshold that separates a recommendation from an Escalation, and the ranking-calibration method for below-threshold possibilities, are deferred design inputs (decision log 0014, open items) and are More information required. They are not defined here. Where either would be outcome-determinative, the agent emits the evidence packet, the reason, and an Escalation rather than a recommendation; any ranked possibilities are explicitly labelled non-recommendatory.
